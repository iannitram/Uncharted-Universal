# Open-issue disposition audit — 2026-11-06

This ledger covers the **95 issues open in the initial snapshot** (`open-issues.json`), including pinned governance issue #23. It is an issue-by-issue source review, not a claim that every remaining defect was reproduced or every game/platform accepted.

## Basis and limits

- Production source was frozen at [`ef27c862dd15f60e64c51a1d285b96dec1be13b9`](https://github.com/iannitram/Uncharted-Universal/tree/ef27c862dd15f60e64c51a1d285b96dec1be13b9); former upstream was [`8b66edc0192ea246ca63b360857402a0aa55626d`](https://github.com/Supermedo/uncharted_pc/tree/8b66edc0192ea246ca63b360857402a0aa55626d). Former upstream is already an ancestor of production, so there is no unmerged upstream batch. Issue state and titles below reflect the initial snapshot; issue-specific notes have since been refreshed where linked.
- Source links are immutable commit permalinks. They show implementation state, not hardware/game acceptance. All non-#66 device, game, performance, and CI checks remain open where stated.
- #66 is the only initial issue closed in this pass. Root measured ten authored synthetic-parser checks (plain ELF/SELF equivalence, malformed header/program-header cases, truncation/extent, both module-linker callers, and `filesz > memsz`). No game dump or game data was used. Rust parity is preserved in successor #206.
- Older audit reports had previously cited 80 Rust and 11 Python tests; those were not rerun for this ledger and are not counted as current verification.
- Fresh follow-up scan after #66 closed and #205–#212 were created reported **102 open issues**. That count is separate from the initial 95-row scope.
