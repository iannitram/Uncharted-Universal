- Owner ruling 2026-11-23 (mobile per-game split and resumable Dropbox game-file downloads):
  - **Split Android and iOS/iPadOS per game:** Uncharted 1, Uncharted 2, and Uncharted 3 ship as **three separate thin apps** on both Android (`7.03` / `#524`, three per-game APKs) and iOS/iPadOS (`8.05` / `#409`, three per-game unsigned `.ipa`s) rather than one combined app, because the combined file size (~55.7 GB for the full collection) would be enormous.
  - **Thin install + resumable first-boot download:** each mobile app downloads, installs, and boots without bundled game assets, then prompts **"Would you like to download the rest of the game files?"** and pulls that game's prepared files from the owner's Dropbox in a **resumable** way (manifest + SHA-256 + byte-offset `.part` checkpointing) so that if the battery dies or the app is force-closed, the download picks right back up where it left off (`8.13` / `#523` for iOS 1.0; `7.04` / `#525` for Android 1.x).
  - **Through `save-relay`'s Dropbox app — built & bug-tested WITH `iannitram/save-relay` (never from scratch):** Both Android and iOS/iPadOS **resumable game-file installs** (`7.04` / `#525`, `8.13` / `#523`) AND **save cloud sync** (`7.05` / `#250`, `9.04` / `#251`) must use the [`iannitram/save-relay`](https://github.com/iannitram/save-relay) repository directly (its Dropbox app, resumable transfer engine, and C FFI / Swift / Android JNI bindings) and be **built and bug-tested together with `save-relay`**. We must **not** build a separate downloader, Dropbox client, or cloud-sync stack from scratch in `Uncharted-Universal` when reaching those stages; any defects found are fixed and tracked with `iannitram/save-relay` (`AGENTS.fork.md`). Codifying the resumable game-file install capability in `save-relay`'s design was tracked in [`iannitram/save-relay#305`](https://github.com/iannitram/save-relay/issues/305) (closed 2026-11-24 by the design PR save-relay#312; implemented in save-relay PR #324). SPEC M11, M12, M15, M17, M18 and the home-network-only Won't are updated to match and wait for owner re-approval.

> **Note for agents (SELF container vs. encrypted dump):** This port executes the game's original x86-64 machine code natively on the host (no CPU emulation) via `crates/runtime` + `gpu/`. Offline prep (`crates/core::prepare::load_image`, formerly `scripts/prepare.py`) accepts PS4 SELF containers (magic `0x1D3D154F`) or plain ELFs and rejects only segments whose SELF segment flags have `encrypted` (`0x2`) or `compressed` (`0x8`) set. Standard Linux `file` reports `data` for PS4 SELF files purely because of the `0x1D3D154F` header magic — **that does not mean the dump is encrypted**. Verify by checking SELF segment flags (or `uncharted-universal check`); all five binaries (`eboot.bin`, `big2-ps4_Shipping.elf`, `big3-ps4_Shipping.elf`, `sce_module/libc.prx`, `sce_module/libSceFios2.prx`) in the Strix Halo dump have `encrypted=0, compressed=0` and are ready to prepare and run.

## Save Relay integration

I've adopted [Save Relay](https://github.com/iannitram/save-relay) for this port's saves. It shares game saves between machines through my own Nextcloud, Google Drive or Dropbox, pulling at launch and pushing at exit, as one small Rust core reused by every game port. Save Relay reached 1.0 on 2026-11-11; every build pins its pre-release tag `v1.0.0-rc.2` (2026-11-18), so a save made on one of my machines is there on the next.

The owner's rulings of 2026-11-17 (Decisions) put save-relay at 1.0 in the Mac app (9.03, #252) and in the iOS/iPadOS apps (9.04, #251), both on the apps of 8.05 (#409). 9.02's 1.0 round trip now covers the Mac and the iPhone or iPad. The owner's rulings of 2026-11-18 (Decisions) make save-relay on in every release build, set up and signed in from the launcher (9.05, #440; from each per-game app on the iPhone or iPad, 9.04), part of 1.0 on every 1.0 platform. By owner ruling 2026-11-23, both **Android and iOS/iPadOS game-file installs** (8.13 #523, 7.04 #525) AND **save cloud sync** (9.04 #251, 7.05 #250) must use [`iannitram/save-relay`](https://github.com/iannitram/save-relay) directly and be **built and bug-tested together with that repo** — never built from scratch in `Uncharted-Universal` when reaching those stages. Codifying the resumable mobile install transfer contract in `save-relay` was tracked in [`iannitram/save-relay#305`](https://github.com/iannitram/save-relay/issues/305) (closed 2026-11-24 by the design PR save-relay#312; implemented in save-relay PR #324).
